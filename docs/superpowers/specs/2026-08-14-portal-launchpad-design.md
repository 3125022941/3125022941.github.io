# 首页功能入口设计

## 目标

将首页改为一屏可理解的个人发布桌面：它只负责展示九尾是谁、目前在构建什么，以及进入项目、笔记、当前构建和关于页面的入口。首页不再承载连续的长篇内容。

## 页面边界

- `index.html`：发布桌面。包含身份、四个明确入口卡片、当前状态和 GitHub；所有核心卡片点击后离开首页。
- `projects.html`：项目档案。展示 Agent Scaffold、AI Architecture Canvas、Agent Ops；只有 Agent Scaffold 指向已确认的 GitHub 仓库。
- `notes.html`：保持现有 22 篇 Agent Scaffold 完整笔记归档。
- `now.html`：当前构建。展示 Agent Scaffold 的进度、技术栈、正在思考的问题和下一步。
- `about.html`：个人简介与 GitHub 入口。

## 导航和链接

全站头部和桌面侧栏使用相同的四个功能入口：项目、笔记、当前构建、关于。首页入口链接为 `projects.html`、`notes.html`、`now.html` 和 `about.html`。每个子页面均提供“返回首页”或品牌链接。

## 视觉与交互

延续纸张底色、深绿、圆角卡片、细颗粒质感、中文衬线标题和日夜主题。首页桌面端展示紧凑的桌面式卡片布局；手机端改为单列卡片。入口卡片有明确的悬停和键盘焦点状态，不能仅用装饰暗示可点击。

## 内容真实性

- 已公开项目只有 Agent Scaffold，链接为 `https://github.com/3125022941/agent-scaffold`。
- AI Architecture Canvas 与 Agent Ops 标记为筹备中，不创建虚构详情链接。
- GitHub 个人主页为 `https://github.com/3125022941`。
- 所有页面保留日夜主题及主题记忆；不引入日历、音乐、推荐等无真实数据的控件。

## 验证

- 自动测试验证首页不再内嵌项目、当前构建或关于的长内容，而是有四个可解析入口。
- 测试验证四个子页面存在、导航互通、外部链接均为已确认地址。
- 浏览器验证首页在桌面和 390px 手机端无横向溢出，入口可用，主题切换可持久化，控制台无错误。
