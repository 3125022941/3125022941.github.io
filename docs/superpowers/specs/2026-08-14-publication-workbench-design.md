# 首页发布工作台设计

## 目标

把首页从线性的个人作品集改为九尾的发布入口。访问者应在一个屏幕内理解：九尾最近发布了什么、有哪些项目、在哪里阅读完整笔记，以及如何访问 GitHub。

## 信息结构

桌面端采用三栏工作台，移动端按相同优先级纵向排列。

1. 左栏为站点身份和固定导航：发布、项目、笔记、关于；当前条目有明确选中状态。
2. 中栏为主要内容：欢迎语、最新发布、项目档案和精选笔记入口。每张卡片只表达一个动作，并链接到真实目标。
3. 右栏为即时状态：正在构建的项目、公开状态、GitHub 入口和最后更新时间。它不包含日历、音乐或其他与项目发布无关的伪功能。

## 内容与链接

- 最新发布：Agent Scaffold 项目页和完整脚手架笔记页。
- 项目档案：已发布的 Agent Scaffold 以及标记为“筹备中”的后续项目；筹备项目不伪造链接。
- 笔记入口：指向 `notes.html`，并提供前三个有代表性的章节锚点。
- 关于：保留电子信息、AI 工程、开源实践的简短身份介绍与 GitHub 个人主页。

## 视觉与交互

- 延续现有纸张底色、深绿、衬线中文标题、圆角和细颗粒质感；不使用截图中的薄荷绿与可爱插画风。
- 卡片通过尺寸、留白和标题层级区分重要性，而非堆砌装饰图标。
- 卡片、导航和主题切换均保持键盘可达；移动端导航可展开且关闭后不进入焦点顺序。
- 点击“发布”“项目”“笔记”“关于”应滚动到对应模块；所有公开链接必须是已确认的真实地址。

## 可靠性与验证

- 继续保留浅色/深色主题和主题记忆。
- 任何屏幕宽度均不得出现横向滚动。
- 自动测试更新为验证四个发布入口、真实项目链接、章节锚点和移动端导航行为。
- 浏览器检查桌面与手机视图，确认导航、卡片和外链可用且控制台无错误。
